# 🎄 ASCII Christmas Card

글자로 만든 3D 크리스마스 트리 위에 나만의 메시지를 담아 보내는 **휴대폰용 크리스마스 카드**예요.
앱 설치나 회원가입 없이, 링크 하나만 보내면 돼요.

**👉 카드 만들러 가기: https://tommyoon0827.github.io/christmas/**

---

## 어떤 카드인가요?

링크를 받은 사람이 열면 이런 순서로 펼쳐져요.

1. 따뜻한 조명 아래 글자로 된 거대한 트리가 3D로 천천히 돌아가요.
2. **트리를 누르면** 꼭대기 별부터 아래로 불이 켜지고, 전구 줄이 나선을 따라 반짝여요.
3. 트리 아래에 **To. 받는 사람**, **메시지(한 글자씩 타이핑)**, **From. 보내는 사람** 순서로 나타나요.
4. 그 뒤로 화면을 누르면 누른 자리에서 반짝이 불꽃이 터져요.

---

## 카드 만드는 방법 (1분)

1. 휴대폰이나 PC에서 **https://tommyoon0827.github.io/christmas/** 를 열어요.
2. 세 칸을 채워요.

   | 칸 | 예시 | 글자 수 |
   |---|---|---|
   | 받는 사람 | Hun | 20자까지 (비워도 돼요) |
   | 메시지 | Merry Christmas! | 300자까지 (꼭 적어야 해요) |
   | 보내는 사람 | Yoon | 20자까지 (비워도 돼요) |

   - 메시지에서 줄을 바꾸면 카드에서도 그대로 줄이 바뀌어요.
   - 받는 사람을 비우면 맨 위에 "Merry Christmas"가 나와요.
3. **✦ 카드 링크 만들기**를 눌러요.
4. 만들어진 링크를 보내요.
   - **공유**: 휴대폰 공유 창이 열려서 카톡, 문자 등으로 바로 보낼 수 있어요. 공유 창을 지원하지 않는 브라우저에서는 이 버튼이 보이지 않아요.
   - **복사**: 링크를 복사해서 원하는 곳에 붙여 넣어요.
   - **미리보기**: 받는 사람이 보게 될 화면을 먼저 볼 수 있어요.

> 💡 **깜짝 선물 팁**: 받는 사람이 처음 링크를 열었을 때 직접 트리를 눌러 불을 켜는 순간이 하이라이트예요. 링크를 보낼 때 "트리를 눌러 봐" 한마디만 같이 보내 보세요.

## 개인정보는 안전한가요?

- 이 카드는 **서버나 데이터베이스가 없어요.** 내가 쓴 메시지는 어디에도 저장되지 않아요.
- 메시지는 **만들어진 링크 주소 안에** 담겨 있어요. 링크를 열면 휴대폰이 주소에서 메시지를 꺼내 화면에 보여 주는 방식이에요.
- 그래서 **링크를 가진 사람은 누구나 메시지를 볼 수 있어요.** 링크를 단체방이나 SNS에 올리면 모두가 볼 수 있으니, 받는 사람에게만 보내 주세요.
- 다른 사람이 만든 카드는 그 링크를 받지 않는 한 볼 수 없어요.
- 비밀번호, 연락처, 주소 같은 민감한 정보는 메시지에 적지 마세요.

## 자주 묻는 질문

**Q. 보낸 메시지를 고칠 수 있나요?**
링크 안에 메시지가 들어 있어서 이미 보낸 링크는 고칠 수 없어요. 고친 메시지로 링크를 새로 만들어서 다시 보내 주세요.

**Q. 링크가 너무 길어요.**
메시지가 링크 안에 들어 있어서 메시지가 길수록 링크도 길어져요. 그대로 보내도 정상이에요. 링크의 일부만 복사하면 카드가 열리지 않으니, **복사**나 **공유** 버튼을 써 주세요.

**Q. "링크가 손상되어 열 수 없어요"라고 나와요.**
링크가 중간에 잘렸을 때 나오는 안내예요. 보낸 사람에게 링크 전체를 다시 보내 달라고 해 주세요.

**Q. 소리는 안 나나요?**
네, 소리 없이 화면으로만 즐기는 카드예요.

**Q. 화면이 버벅여요.**
글자 수천 개를 실시간으로 돌리기 때문에 오래된 휴대폰에서는 조금 느릴 수 있어요. 다른 앱을 닫고 다시 열어 보세요.

**Q. 어떤 브라우저에서 되나요?**
최신 휴대폰 브라우저(사파리, 크롬, 삼성 인터넷)와 PC 브라우저에서 열려요. 카톡 등 메신저 안에서 열었을 때 화면이 이상하면, 오른쪽 위 메뉴에서 "다른 브라우저로 열기"를 눌러 보세요.

**Q. 돈이 드나요?**
아니요. 무료이고 광고도 없어요.

## 만든 방법 (궁금한 분만)

- HTML 파일 한 개(`index.html`)로 만들었어요. 외부 라이브러리 없이 Canvas로 그려요.
- 3D 효과는 원뿔 위에 글자 2,500여 개를 배치하고, 회전시키면서 원근에 따라 크기와 밝기를 바꿔서 만들어요.
- 메시지는 UTF-8 → Base64(URL용)로 바꿔 주소의 `#` 뒤에 붙여요. `#` 뒤 내용은 서버로 전송되지 않아요.
- GitHub Pages로 무료로 배포하고 있어요.
